# Hotel Room Booking System

## Introduction

Hotel Room Booking System is a Python-based terminal application
for managing hotel rooms and customer bookings.

## Features

- View hotel rooms
- Book a room
- Search booking using Booking ID
- Cancel a booking
- Check-out
- Generate final bill
- Calculate room charges based on number of nights

## Technologies Used

- Python 3
- Lists
- Dictionaries
- Functions
- Loops
- Conditional Statements

## Requirements

Python 3.x

No external libraries are required.

## How to Run

1. Install Python 3.x.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

`bash
python "room booking system.py"
